# Лицензии

Это открытый некоммерческий проект на основе исходников Quake III Arena, которые id Software
выпустила под GPL в 2005 году. Ниже перечислено, что под какой лицензией и что в проект не входит.

## Код движка — GNU GPL v2

Весь код движка, игровой логики (`code/game`, `code/cgame`, `code/ui`), инструментов и редактора
распространяется под GNU General Public License версии 2. Полный текст лицензии — в `COPYING.txt`.
Исходное уведомление id Software — в `README.txt`. Оба файла должны оставаться в проекте.

Изменения этого форка тоже распространяются под GPL v2. Это загрузчик моделей glTF
`code/renderer/tr_model_glb.c`, сборка через MinGW `code/Makefile.mingw` и правки в остальных файлах.

При раздаче готовой сборки (`Walker.exe`) нужно дать доступ к её исходникам. Достаточно указать
ссылку на этот репозиторий и на коммит, из которого сделана сборка.

## Код не под GPL

В выпуске id Software есть файлы со своими лицензиями. Все они разрешают свободное распространение,
если сохранять уведомления об авторах в самих файлах. Полные тексты лицензий — в `README.txt`
(раздел LICENSE) и в указанных файлах.

| Файлы | Что это | Лицензия, условие |
|---|---|---|
| `code/qcommon/unzip.c`, `libs/pak/unzip.cpp` | чтение .zip (на основе zlib) | лицензия zlib: не выдавать за свой код, изменённые версии помечать |
| `code/qcommon/md4.c`, `common/md4.c` | алгоритм MD4 | RSA Data Security: в документации называть «RSA Data Security, Inc. MD4 Message-Digest Algorithm» |
| `code/game/bg_lib.c` | замена функций стандартной библиотеки C | BSD (University of California) с условием упоминания |
| `code/client/snd_adpcm.c` | кодек ADPCM | Stichting Mathematisch Centrum: сохранять уведомление |
| `code/jpeg-6`, `libs/jpeg6` | библиотека JPEG | IJG: при раздаче только исполняемого файла указать в документации «this software is based in part on the work of the Independent JPEG Group» |
| `lcc/` | компилятор lcc (собирает QVM) | собственная лицензия, файл `lcc/COPYRIGHT`: раздавать можно бесплатно с этим файлом, продавать нельзя |

Эта сборка основана в том числе на работе Independent JPEG Group
(this software is based in part on the work of the Independent JPEG Group).

## Модель игрока walker — CC BY-SA 4.0

Модель шагающего робота walker из папки `assets/` распространяется под лицензией
Creative Commons «С указанием авторства — С сохранением условий» 4.0 Международная
(CC BY-SA 4.0): https://creativecommons.org/licenses/by-sa/4.0/deed.ru

Это геометрия, анимации, текстуры, скины, шейдер и иконки в файлах:
- `assets/zz-walker.pk3`,
- `assets/zz-walker-md3.pk3`,
- `assets/baseq3/`.

Модель сделана для этого проекта с нуля, материалы из Quake III в ней не использованы.

Автор: diakin (https://github.com/diakin/Quake-III-Arena).

Модель можно копировать, раздавать и переделывать, в том числе в своих проектах. Условия:
- указывать автора и ссылку на лицензию;
- переделанную модель распространять под той же лицензией CC BY-SA 4.0.

## Собственные данные игры WALKER — CC BY-SA 4.0

Игра WALKER (папка `basewalker`) не использует данные Quake III. Все её данные созданы заново
скриптами из `walker/tools/`:
- `make_basedata.py` — настройки, шрифты, меню, прицелы, цифры, иконки, эффекты;
- `make_sounds.py` — все звуки, синтезированы программно, записи и сэмплы со стороны не используются;
- `make_map_islands.py` — карта wk_islands: рельеф, постройки, текстуры, небо, шейдеры.
- `make_botfiles.py` — файлы ботов (характеры, настройки оружия, фразы) и окраски робота desert и urban;
  заголовки `chars.h` и `inv.h` копируются из `code/game` (GPL v2).

Исключение — звук шагов по воде: он вырезан из записи `walker/sounds/footsteps_water.mp3`
(скрипт `import_splash.py`). Запись предоставил автор проекта; её источник и лицензию нужно
указать здесь перед публичной раздачей игры.

Сами скрипты — часть исходников проекта и распространяются под GPL v2. Созданные ими данные
(`walker/dist/basewalker/*.pk3`, `walker/maps/levelshots/`) — под CC BY-SA 4.0, как и модель walker.
Автор: diakin.

Буквы в шрифтах и на текстурах нарисованы с помощью шрифтов DejaVu (лицензия Bitstream Vera /
DejaVu, свободная) и Anton (SIL Open Font License 1.1). Обе лицензии разрешают использовать
отрисованные этими шрифтами изображения без ограничений; сами файлы шрифтов в игру не входят.

## Данные игры Quake III — не входят

Под GPL открыт только код. Данные игры остаются собственностью правообладателя и под GPL не подпадают:
карты, модели, текстуры, звуки и музыка из `baseq3/pak0.pk3` ... `pak8.pk3`.

В этом репозитории их нет, и раздавать их вместе с проектом нельзя. Для игры нужна своя копия
Quake III Arena, либо весь контент нужно заменить собственным.

## Товарные знаки

«Quake», «Quake III Arena» и «id Software» — товарные знаки их владельцев. Проект не связан с ними
и не одобрен ими. Эти названия и логотипы нельзя использовать как имя проекта. В описании допустимо
написать «на основе исходников Quake III Arena (GPL)».
